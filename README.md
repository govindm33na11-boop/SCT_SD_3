# 🧩 Sudoku Solver - SkillCraft Technology (Task 03)

An intelligent desktop application built with Python and native Tkinter that automatically solves 9x9 Sudoku puzzles using a recursive backtracking algorithm.

---

## ✨ Features
* **Interactive 9x9 Board Grid:** Styled with a clean editorial minimalist layout and custom cell boundaries.
* **Backtracking Algorithm Engine:** Fast automated computation to solve standard and complex Sudoku grids.
* **Sample Loader & Clear Controls:** Includes built-in sample puzzles for instant testing.
* **Maximizable & Resizable:** Fully responsive layout with zero external dependencies.

---

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **GUI Framework:** Tkinter (Standard Library)
